# Weather Diary

## Автор
Тихоньких Макар

## Описание
Приложение с графическим интерфейсом для записи и просмотра погодных данных.

Функции:
- добавление записей
- фильтрация по дате
- фильтрация по температуре
- сохранение данных в JSON

## Запуск
python main.py

## Использование
1. Ввести дату в формате ДД.ММ.ГГГГ
2. Ввести температуру
3. Ввести описание погоды
4. Выбрать осадки
5. Нажать "Добавить запись"

## Проверка
- Пустые поля → ошибка
- Неверный формат даты → ошибка
- Температура не число → ошибка
