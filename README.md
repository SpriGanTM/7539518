# Weather Diary

## Автор
Тихоньких Макар 454 группа

## Описание
Приложение для записи и просмотра погодных данных.

Функции:
- добавление записей
- фильтрация по дате
- фильтрация по температуре
- сохранение в JSON

## Запуск
python main.py

## Использование
1. Ввести дату (ДД.ММ.ГГГГ)
2. Ввести температуру
3. Ввести описание
4. Выбрать осадки
5. Нажать "Добавить запись"

## Проверки
- Пустые поля → ошибка
- Неверная температура → ошибка
- Неверная дата → ошибка
